关于

这里是 墨笺 · Ink Letter，一个用来安放想法的地方。

写点什么来介绍你自己吧 —— 你是谁，在哪里，关心什么，以及为什么开始写这个博客。这段文字会出现在「关于」页面。直接编辑 about.html 里的这段 <div class="prose"> 即可，支持完整的 HTML 排版。

这个博客是怎么搭起来的

它是一个纯静态站点：文章以 Markdown 写就，放在 posts/ 目录下；浏览器读取 posts/index.json 索引并渲染列表与正文。不需要数据库，不需要服务端，推送到 GitHub 即自动发布。

  • 其它 —— 自行补充
