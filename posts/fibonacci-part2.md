上一篇[《斐波那契数列与黄金分割》](fibonacci.md)里,我用特征方程推出了比奈公式,临了留下一句话:

> 建议你自己动手写过一遍,那才是"原来如此"的最佳体验。

今天就把它写完。而且写两遍:第一遍用最简单的工具——等比数列加韦达定理,全程没有超出初中代数;第二遍用生成函数,把上次只给了一句话的部分分式分解完整走一遍。

## 一、简单版:把递推"拧"成等比数列

等比数列是最可爱的递推:知道首项和公比,一切就都知道了。我们的目标是把二阶递推

$$F_n = F_{n-1} + F_{n-2}$$

改写成"$F_n - \alpha F_{n-1}$ 成等比"的形式。为此尝试

$$F_n - \alpha F_{n-1} = \beta\big(F_{n-1} - \alpha F_{n-2}\big) \tag{1}$$

展开右边并整理:

$$F_n = (\alpha + \beta)F_{n-1} - \alpha\beta\, F_{n-2}$$

要和原递推逐项对应,必须

$$\alpha + \beta = 1, \qquad \alpha\beta = -1$$

由韦达定理,$\alpha, \beta$ 正是 $t^2 - t - 1 = 0$ 的两个根,即

$$\varphi = \frac{1+\sqrt5}{2}, \qquad \psi = \frac{1-\sqrt5}{2}$$

注意:这里连"特征方程"这个词都没出现,有的只是"两个数,和为 1,积为 -1"——初等代数而已。(熟悉上一篇的人会发现,这其实就是特征方程法的另一种长相:$t^2-t-1=0$ 正是令 $F_n = r^n$ 代入递推后得到的那个方程。)

现在回到 (1),取 $\alpha = \varphi,\ \beta = \psi$。右边的数列 $\{F_n - \varphi F_{n-1}\}$ 是公比为 $\psi$ 的等比数列,首项 $F_1 - \varphi F_0 = 1$,于是

$$F_n - \varphi F_{n-1} = \psi^{\,n-1} \tag{2}$$

完全对称地,交换 $\varphi$ 与 $\psi$ 的角色:

$$F_n - \psi F_{n-1} = \varphi^{\,n-1} \tag{3}$$

用 (3) 减 (2):

$$(\varphi - \psi)\,F_{n-1} = \varphi^{\,n-1} - \psi^{\,n-1}$$

而 $\varphi - \psi = \sqrt5$,平移下标即得**比奈公式**:

$$F_n = \frac{\varphi^{\,n} - \psi^{\,n}}{\sqrt5}$$

全程最高级的工具就是"等比数列"和"韦达定理"。这就是我理解的简单证明:不是偷工减料,而是骨头刚好这么多。

## 二、大锤版:生成函数

这一版思路完全不同:不和递推纠缠,而是把整个数列**打包**成一个幂级数

$$G(x) = \sum_{n\ge 0} F_n x^n = 0 + x + x^2 + 2x^3 + 3x^4 + 5x^5 + \cdots$$

然后问一个更粗的问题:这个无穷长的级数,能不能压缩成一个简洁的封闭形式?如果能,比奈公式就藏在它的系数里。

### 第一步:递推变成方程

利用 $F_n = F_{n-1}+F_{n-2}$(对 $n\ge2$):

$$\begin{aligned}
G(x) &= F_0 + F_1x + \sum_{n\ge2} F_n x^n \\[2pt]
&= x + \sum_{n\ge2}\big(F_{n-1} + F_{n-2}\big)x^n \\[2pt]
&= x + x\sum_{n\ge1} F_n x^{n-1} + x^2\sum_{n\ge2} F_n x^{n-2} \\[2pt]
&= x + xG(x) + x^2G(x)
\end{aligned}$$

第三行到第四行是唯一需要放慢脚步的地方:$F_{n-1}x^n = x \cdot F_{n-1}x^{n-1}$,提一个 $x$ 出来之后下标恰好从 0 开始;第二个和式同理。一切都刚好对上——这就是生成函数令人上瘾的原因。解方程得

$$G(x) = \frac{x}{1-x-x^2}$$

到此,"求通项"变成了"把有理函数展开成幂级数"——一个机械到可以无脑完成的任务。

### 第二步:部分分式

先因式分解分母。由于 $\varphi+\psi=1,\ \varphi\psi=-1$,直接验证:

$$(1-\varphi x)(1-\psi x) = 1 - (\varphi+\psi)x + \varphi\psi x^2 = 1 - x - x^2$$

于是设

$$\frac{x}{1-x-x^2} = \frac{A}{1-\varphi x} + \frac{B}{1-\psi x}$$

通分、比较分子:

$$x = A(1-\psi x) + B(1-\varphi x)$$

看 $x^0$ 的系数得 $A + B = 0$;看 $x^1$ 的系数得 $-A\psi - B\varphi = 1$。解得 $A = \dfrac{1}{\sqrt5},\ B = -\dfrac{1}{\sqrt5}$,即

$$G(x) = \frac{1}{\sqrt5}\left(\frac{1}{1-\varphi x} - \frac{1}{1-\psi x}\right)$$

### 第三步:展开,提取系数

几何级数 $\dfrac{1}{1-\varphi x} = \sum_{n\ge0}\varphi^{\,n}x^n$ 是任何幂级数问题的基础款:

$$G(x) = \frac{1}{\sqrt5}\sum_{n\ge0}\big(\varphi^{\,n} - \psi^{\,n}\big)x^n$$

比奈公式从系数里自己滚了出来:

$$\boxed{\,F_n = \frac{\varphi^{\,n} - \psi^{\,n}}{\sqrt5}\,}$$

## 三、两把武器,同一件事

- **简单版**难在开头那一"拧":要想到能把递推改写成等比数列。一旦想到,后面一路畅通,每步都是看得懂、算得出的初等代数。
- **生成函数**开头是机械的(递推翻译成方程,谁都会),难的是"把数列打包成级数"这个视角本身。但一旦打包成功,后续就全是代数——而且它对**所有**线性递推一视同仁,不需要每次重新想。

其实两者必然殊途同归,因为它们就是同一个公式的两条路。把 $F_n = \dfrac{\varphi^n - \psi^n}{\sqrt5}$ 代回 $G(x)$ 的定义,你会得到同一个分式 $\dfrac{x}{1-x-x^2}$。

幂级数就是数列的"另一个坐标系":同一个对象,换个视角看,原本藏在递推里的结构立刻透明。

## 四、延伸:换个数列试试手

比奈公式到此已经推了两遍,斐波那契的账结清了。但生成函数这门手艺刚热完身就收工,有点可惜。同样是卷积型递推,还有一个著名的数列:

> **卡特兰数**满足 $C_0 = 1,\ C_{n+1} = \sum_{k=0}^{n} C_k C_{n-k}$,其通项是 $C_n = \dfrac{1}{n+1}\binom{2n}{n}$——括号序列、二叉树、凸多边形三角剖分……到处都是它。

按今天的路子推一遍:设 $C(x) = \sum C_n x^n$,观察 $C(x)^2$ 的系数,它正好是 $\sum_{k} C_k C_{n-k}$,也就是 $C_{n+1}$ 的卷积。剩下的交给代数,和今天一样。
