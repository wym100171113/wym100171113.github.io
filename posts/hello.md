欢迎来到我的博客。这是第一篇文章，用来介绍一下这个博客是什么、不是什么。

## 为什么写

Matrix67 在采访里说，做博客最大的成就感，是**把某个非常复杂的东西，用一种自己读来赏心悦目的方式写了出来**。

这句话我很喜欢。写东西最好的一刻，不是写完的时候，而是讲到一半、忽然自己也想明白的那一刻——"原来如此"。

这个博客的目的很简单：记录那些"原来如此"的时刻。

## 写什么

暂时打算写三类内容：

1. **数学**：有趣的定理、证明、脑筋急转弯式的小问题；
2. **代码**：踩过的坑、想通的道理、好玩的实现；
3. **随笔**：关于界面、设计与留白的杂想。

## 不是什么

不是新闻站，不是教程站，更不是营销号。更新随缘，篇幅随缘。

## 技术说明

本站是完全静态的：文章是一份份 Markdown 文件，放在 `posts/` 目录；`git push` 之后，GitHub Actions 会自动重建索引并发布到 GitHub Pages。

如果你想把这套博客架到自己名下，流程大概是：

```bash
git clone https://github.com/wym100171113/wym100171113.github.io
python3 tools/blog.py new "我的第一篇文章"
python3 tools/blog.py build
python3 tools/blog.py publish "第一篇文章" --push
```

一分钟，上线。
