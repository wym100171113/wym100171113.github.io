生成函数是个奇怪的东西:它把一个无穷数列(一堆散装数字)打包成一个"函数"(一个整体),之后对数列的一切操作——求和、卷积、解递推——都变成了代数运算。

上一篇《[再谈斐波那契](post.html?slug=fibonacci-part2)》里我们已经用它推过比奈公式,但那是"用",没讲"是什么"。这篇补课,顺便兑现上一篇末尾埋下的卡特兰数。

## 打包:什么是生成函数

定义简单得不像话。给定数列 $a_0, a_1, a_2, \dots$,它的(普通)生成函数是

$$G(x) = \sum_{n\ge 0} a_n x^n = a_0 + a_1 x + a_2 x^2 + \cdots$$

$x$ 本身没有任何数学意义,它只是一个**提货单**:我们约定 $a_n$ 住在 $x^n$ 那一格。生成函数就是数列的完整档案袋——系数是内容,$x$ 是坐标。

几个最基本的例子:

| 数列 | 生成函数 | 由来 |
|------|---------|------|
| $1,1,1,\dots$ | $\dfrac{1}{1-x}$ | 几何级数 |
| $1,2,3,\dots$ | $\dfrac{1}{(1-x)^2}$ | 上一行求导 |
| $0,1,2,3,\dots$ | $\dfrac{x}{(1-x)^2}$ | 再乘 $x$ |
| $1,r,r^2,\dots$ | $\dfrac{1}{1-rx}$ | 等比数列 |

最后一行是万能砖:**"每项乘个常数"的数列,生成函数就是除以 $1-rx$**。前两行都是它的推论——对 $\frac{1}{1-x} = \sum x^n$ 求导,得 $\frac{1}{(1-x)^2} = \sum (n{+}1)x^n$,系数确实是从 $1$ 数的自然数。

## 打包之后:数列的运算变成代数

这是生成函数真正值钱的地方。设 $A(x) = \sum a_n x^n$、$B(x) = \sum b_n x^n$。

**加法**是平凡的:$A(x) + B(x)$ 的系数就是 $a_n + b_n$。

**位移**(右移一格,补 $a_{-1}=0$)就是乘 $x$:

$$x\,A(x) = \sum a_n x^{n+1}$$

**卷积**才是主角。两个数列的卷积 $c_n = \sum_{k=0}^{n} a_k b_{n-k}$ 恰好是乘积的系数:

$$A(x)B(x) = \sum_{n\ge0}\left(\sum_{k=0}^{n} a_k b_{n-k}\right)x^n$$

为什么卷积这么重要?因为**大量递推天然就是卷积**——卡特兰数是,斐波那契也算(它是位移加加法,最朴素的卷积)。

## 解递推的标准流程

用这套语言把上一篇的过程重述一遍,现在它看起来像一条流水线:

1. **递推 → 方程**:把 $F_n = F_{n-1} + F_{n-2}$ 翻译成 $G = x + xG + x^2G$,解得封闭形式 $G(x) = \dfrac{x}{1-x-x^2}$;
2. **封闭形式 → 可展开**:部分分式 $\dfrac{x}{1-x-x^2} = \dfrac{1}{\sqrt5}\left(\dfrac{1}{1-\varphi x} - \dfrac{1}{1-\psi x}\right)$;
3. **展开 → 通项**:用"万能砖" $\frac{1}{1-rx} = \sum r^n x^n$,系数即 $F_n = \dfrac{\varphi^n - \psi^n}{\sqrt5}$。

**三步:递推 → 封闭形式 → 展开。** 所有线性递推都走这条路,差别只在第二步的技巧深浅。

## 卡特兰数:卷积的正式登场

上一篇末尾埋了伏笔。卡特兰数满足 $C_0 = 1$ 与卷积型递推

$$C_{n+1} = \sum_{k=0}^{n} C_k C_{n-k}$$

右边正是 $(C*C)_n$。用生成函数的语言,整条递推缩写成一行:

$$C(x) = 1 + x\,C(x)^2$$

(想清楚这句:左边是 $C$ 加上首项;右边,卷积对应乘积 $C(x)^2$,乘以 $x$ 是补上 $C_{n+1}$ 与 $C_n$ 之间的位移。建议停下来自己推一遍,那才是"原来如此"。)

解这个关于 $C(x)$ 的二次方程($x$ 只是系数):

$$C(x) = \frac{1 \pm \sqrt{1-4x}}{2x}$$

取哪个号?$x \to 0$ 时应有 $C(x) \to C_0 = 1$。取正号时分子 $\to 2$、除以 $x$ 会爆掉;所以取负号:

$$C(x) = \frac{1 - \sqrt{1-4x}}{2x}$$

现在展开。用二项式定理,但这次指数是 $\tfrac12$(分数次幂,照常展开,系数是 $\binom{1/2}{k}$,只在乎前几项):

$$(1-4x)^{1/2} = 1 - 2x - 2x^2 - 4x^3 - 10x^4 - 28x^5 - \cdots$$

于是

$$C(x) = \frac{1-\sqrt{1-4x}}{2x} = 1 + x + 2x^2 + 5x^3 + 14x^4 + \cdots$$

$1, 1, 2, 5, 14$——卡特兰数,一个不少,自己从系数里走了出来。

一般项的公式也能从同一展开里读出来(提取 $x^{n+1}$ 的系数):

$$C_n = \frac{1}{n+1}\binom{2n}{n}$$

括号序列、二叉树、凸多边形三角剖分……这些风马牛不相及的计数对象长着同一张脸,因为它们的递推是同一个卷积。

## 尾声:不是魔法

回头看看生成函数到底做了什么:它把**对数列的操作**翻译成**对多项式的操作**。翻译之前,递推是一条条算的局部规则,像流水账;翻译之后,整个数列变成一个整体对象,可以整体地解方程。

上面 $(1-4x)^{1/2}$ 的展开系数里有分数,组合出来却全是整数——代数把"猜"变成了"算",这是它最有说服力的一刻。

> 小注:本文用的是普通生成函数(OGF),适合"选或不选"的计数;还有指数型生成函数(EGF),适合有顺序的排列计数。那是另一篇的故事。
